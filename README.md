# NJLocalTies CRM

Sales CRM with a built-in prospecting and lead-generation engine for NJLocalTies (njlocalties.com).

## Status

**Phase 0 — proposal.** No application code yet. See [`docs/phase-0-proposal.md`](docs/phase-0-proposal.md) for the recommended architecture, costs, timeline, compliance constraints and open questions. Phase 1 (pilot build) starts after the proposal is approved.

## Ground rules

- No API keys or secrets in this repository — use environment variables.
- No real calls or emails during development; test records and test inboxes only.
